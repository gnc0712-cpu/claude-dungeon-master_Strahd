# Book Excerpts Needed

This is the working checklist of official-book content Reloaded references but doesn't reproduce. It's built from the actual citations found in `reference/curse-of-strahd-reloaded/` — not guesswork — so it should stay close to complete for anything covered by the guide's main critical path.

**How this works:** give me each item once, from your own copy of the book, and I'll save it into `reference/excerpts/` so it's there for every future session and every new chat — no re-sending. Check items off as they're captured. Short excerpts only (a stat block, a feat, a specific paragraph) — not whole chapters.

**Edition note:** Reloaded is written for **2014 rules** (its own intro says so explicitly) and assumes the 2014 PHB/DMG/MM plus Xanathar's Guide and Van Richten's Guide. Your books are 2024 editions. Where a citation below is a monster stat block or feat, giving me the 2024 version is fine — I'll adjudicate the (usually small) differences. Flag it to me if something reads as a bigger mechanical change than expected.

## Tier 4 — Original *Curse of Strahd* module (gathered per-arc, not upfront)

Reloaded's "Brand-New Barovia" rule: if the guide references a specific room/section of the original book by page number, you use that section as-is unless Reloaded overrides it; if the guide *doesn't* reference something, it doesn't exist in this campaign. That means there are dozens of small page citations scattered across all 21 arcs (e.g. "E2. Blood of the Vine Tavern, p. 43") — too many to usefully front-load now, and most only matter the one time the party is actually in that room.

The workflow for these: when we're about to run an arc that cites the original book, I'll flag exactly which page(s) it needs *before* that session (not mid-scene), you grab it once, and it goes into `reference/excerpts/` under that arc's name — permanent after that.

- [x] **Arc A — Escape From Death House** — captured in full in `reference/excerpts/arc-a-death-house-appendix-b.md` (Appendix B, the entire Death House dungeon, all 38 areas).
