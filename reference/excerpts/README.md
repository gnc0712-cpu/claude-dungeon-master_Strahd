# Book Excerpts

Short, user-provided excerpts from officially owned books, captured once and reused across every future session. See `reference/book-excerpts-needed.md` for the checklist of what's still outstanding.

One file per topic (e.g. `vampire-spawn.md`, `arc-a-death-house.md`). Keep entries short — a stat block, a feat, a specific room's text — not whole chapters or books.
